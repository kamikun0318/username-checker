# Username Checker + Auto ID Finder

DNS Robot風のマルチプラットフォームユーザー名空きチェッカー + 自動空きID探しBot

## 機能

### 1. 一括チェッカー
- ユーザー名を入力して複数プラットフォームの空き状況を一括確認
- 対応予定: GitHub, Discord, Twitter/X, Reddit, YouTube, Twitch など

### 2. 自動空きID探し (Bot)
- 文字数指定（4〜8文字など）
- ランダム生成 or パターン指定で空きIDを自動探索
- 見つかった空きIDを一覧表示

## 技術スタック
- Next.js (App Router)
- Vercel デプロイ
- Tailwind CSS
